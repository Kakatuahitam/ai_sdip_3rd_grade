The components being used in the project seems too many, but most of them actually comes from a single component that is **looks effect**. It allows us to do many things, here are the things:

```{figure} ../_static/images/content/13/looks.png
:label: seven_looks
:alt: seven looks effects

These are the easy tool to add some joy on Scratch 3.0
```
We will demonstrate the visual changes using repeat block

### 1. Color

```{figure} ../_static/images/content/13/300px-Color_effect.png
:label: color_scale
:alt: color scale

So, to make it turn back into its original colour, make sure to loop into 200
```
The color will modify the objects to looks like changing its color with in a scale. It modifies the hue value. And you have to know that it has scale from 0-200 only.

```{figure} ../_static/images/content/13/color_changes.mp4
:label: color_changes
:alt: color changes applied

Like a chameleon, we may change the sprite color.
```

### 2. Fish Eye
```{figure} ../_static/images/content/13/fisheye.mp4
:label: fisheye
:alt: inflating sprite

Watch out! Will it explode?
```

```{figure} ../_static/images/content/13/fisheye_neg.mp4
:label: fisheye_neg
```

There is no maximum value for the `fisheye` effect, but the minimum is `-100`


### 3. Whirl
```{figure} ../_static/images/content/13/whirl.mp4
:label: whirl
:alt: uh dizzy

This is also not `kamui`
```

This one has no minimum or maximum value, so take your time to revert the effect

### 4. Pixelate
```{figure} ../_static/images/content/13/pixelate.mp4
:label: pixelate
:alt: pixelating sprite

Yes, it may blur your vision as you like
```

This one has no maximum value, but it may not be used with less than 0 value

### 5. Mosaic
```{figure} ../_static/images/content/13/mosaic.mp4
:label: mosaic
:alt: duplicating sprite

Although it will be many, but actually it is only one object
```

This one has maximum value it is 5105 and not less than 0

### 6. Brightness
```{figure} ../_static/images/content/13/brightness.mp4
:label: brightness
:alt: bright and dark sprite

Ouch, my eye!
```

This one maximum value is 100 and the minimum is -100. 100 makes the sprite absolutely bright (white) and the -100 becomes dark (black

### 7. Ghost

And the last one, this one only has 0-100 value from visible to transparent
